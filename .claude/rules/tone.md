# 톤 규칙

새로 쓰거나 고치는 모든 파일에 적용한다. 노트북(`.ipynb`)은 실험 기록이라 제외한다.

## 어체

| 대상 | 어체 | 예 |
|---|---|---|
| 코드 주석·docstring·섹션 구분선 | 한국어 명사형 개조식, 마침표 없음 | `# 검색기 정의`, `"""Pinecone MMR 검색기 반환"""` |
| 터미널 로그(`print`) | 아이콘 + 명사형 + ` : ` 대상 | `✗ 다운로드 에러 : {url} \| 사유: {e}` |
| 앱 UI 문구(버튼·안내·상태) | 해요체 | `✓ 키가 저장됐어요. 이제 질문할 수 있어요.` |
| 사용자 문서(README) | 합니다체 | `데모는 … 확인 가능합니다.` |
| 내부 문서(CLAUDE.md, `.claude/`, `docs/`) | 한다체 개조식 | `커밋은 /git-commit 스킬로 한다.` |
| LLM 프롬프트(`prompts.py`) | 합니다체 지시문, 기존 문구 유지 | `…스님 화법으로 답변하세요.` |
| 커밋 메시지 | Conventional Commits, 접두어 영어 + 한국어 | `fix(app): …` |

## 아이콘

컬러 이모지는 쓰지 않는다. 아래 단색 유니코드 기호만 쓴다. `⚠ ☸ ⚙`은 이모지로 바뀌지 않도록 뒤에 U+FE0E(텍스트 표시 선택자)를 붙인다.

| 의미 | 기호 | 의미 | 기호 |
|---|---|---|---|
| 성공 | ✓ | 안내·참고 | ※ |
| 실패·오류 | ✗ | 키·인증 | ⚿ |
| 경고 | ⚠︎ | 항목 강조 | ▸ |
| 진행·준비 | ↻ | 도구·구성 | ⚙︎ |
| 검색 | ⌕ | 서비스 상징(제목) | ☸︎ |
| 생성 중 | … | | |

- 목록에 없는 의미가 필요하면 기호를 새로 만들기 전에 사용자에게 확인하고, 확정되면 이 표에 추가한다.
- 문장마다 아이콘을 붙이지 않는다. 상태·안내 줄의 맨 앞에만 쓴다.

## 코드 작성 원칙

- 핵심만 간결하게 쓰되 가독성을 우선한다. 한 줄로 줄이려고 의미를 숨기지 않는다.
- 주석은 '무엇'이 아니라 코드만으로 드러나지 않는 '왜'를 적는다. 자명한 줄에는 달지 않는다.
- docstring은 한 줄 요약을 기본으로 하고, 인자가 자명하지 않을 때만 Google 스타일 `Args:`/`Returns:`를 붙인다.
- 타입 힌트는 내장 제네릭(`list[str]`, `dict[str, Any]`)을 쓴다.
- 주석 처리된 죽은 코드는 남기지 않는다.
